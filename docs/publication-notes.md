# 공개용 저장소 안내

학교 캡스톤 팀 프로젝트의 공개용 사본입니다. 원본 팀 저장소는 비공개로 별도 보관합니다.

## 개발 이력과 민감정보 정리

과거 커밋의 로컬 DB 비밀번호를 예시 값으로 교체했습니다. 작성자·작업 날짜·커밋 메시지와 개발 이력은 보존했으며, 정리 과정에서 커밋 ID가 변경됐습니다. 원본 PR·이슈·댓글은 이전하지 않았습니다.


## 문서 보존

[개발 당시 팀 문서](team-readme.md)에 원래 README를 보존했습니다. 과거 서버 IP는 로컬 예시 주소로 바꿨으며, 당시 기술 버전·진행 상황은 현재 실행 상태를 보장하지 않습니다.

## 검증 범위

공개용 정리 과정에서 비밀번호 노출 여부와 기록 보존을 검사했습니다. 현재 환경에서 백엔드 설치·실행과 DB·S3 연동은 재검증하지 않았습니다.
